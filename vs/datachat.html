DataChat



About DataChat

DataChat lets users analyze data and uncover insights in real-time—simply by asking questions in plain English. It integrates seamlessly with popular data warehouses like Snowflake, BigQuery, Databricks, and AWS Redshift.


My Contributions

I was promoted to Senior Software Engineer 1 in January 2025 and joined the release team, which is responsible for managing hosted environments (development and production servers), CI/CD pipelines, cloud assets, and the software development processes. So far I have worked on:

Load Testing Initiative: Proposed and implemented the adoption of the Artillery load testing tool to effectively evaluate the performance and scalability of DataChat's SaaS platform. The load testing initiative uncovered scalability bottlenecks that were impeding application performance.

  • Researched and compared various load testing tools to identify the best fit for the platform's requirements.
  • Set up Playwright scripts to simulate user interactions with the application for realistic load scenarios.
  • Configured AWS Lambda and ElastiCache via Terraform to manage application users and session state for distributed load tests.
  • Established CI triggers to automatically run distributed load tests with multiple workers on AWS Fargate, enabling scalable and automated performance testing.

CI/CD Initiative: Led efforts to modernize deployment and release processes for DataChat's hosted environments.

  • Researched and evaluated deployment strategies to identify the most effective approach for minimizing downtime and manual intervention during production upgrades.
  • Integrated Argo Rollouts with DataChat's hosted Kubernetes environments to enable zero-downtime production upgrades.
  • Reduced manual deployment effort and advanced the organization toward a fully cloud-native CI/CD pipeline.

VertexAI Vector Search Integration: Led a team of three developers to overhaul DataChat's vector database library and services, enabling support for multiple vector database providers, including VertexAI Vector Search and Milvus.

  • Architected and guided the redesign of the vector database abstraction layer to allow seamless integration with different providers.
  • Provided hands-on support to team members with debugging challenging issues during the migration and integration process.
  • Reviewed and approved complex pull requests, ensuring code quality and maintainability throughout the project.

Before that, I was a Software Engineer 2 in the ML and GenAI team, contributing to the company's flagship product "Ava," which offers users a simple chat-based interface to ask freeform questions about their data and leverage generative AI for insights.

Post-Processing Framework Design: Co-led the design and implementation of a robust post-processing framework for the GenAI team, where I:

  • Developed advanced node and graph-based structures to sanitize and process Python code responses generated by LLMs.
  • Engineered translation of processed Python workflows to DataChat Guided English Language, the company's custom SQL execution abstraction language.
  • Enabled seamless and safe execution of user queries by bridging LLM output with DataChat's backend systems.

LLM Evaluation Framework: Helped set up the LLM Evaluation Framework for the GenAI team.

  • Proposed the refactor to make the framework fully cloud native, guided a developer through the implementation, and reviewed their work to ensure quality and maintainability. This enabled scalable and efficient evaluation workflows.
  • Accelerated the team's ability to benchmark, adopt, and iterate on different LLMs, increasing flexibility and agility in product development.

GenAI Scalability Improvements: Led a project to enhance the scalability and efficiency of the GenAI platform.

  • Implemented Horizontal Pod Autoscaling (HPA) policies for all GenAI microservices after conducting targeted load tests to identify scaling needs.
  • Refactored the microservice responsible for LLM interactions to be multithreaded by moving the in-memory embedding model, which was not threadsafe, to a standalone service, improving throughput and reliability.
  • Reevaluated and optimized CPU and RAM resource allocations for all microservices in the GenAI stack, ensuring efficient use of cloud resources.
  • These improvements resulted in a sizable reduction in Kubernetes-related cloud costs for that month and onwards.

Azure Application Gateway for OpenAI Resource Pooling: Architected the use of the Azure Application Gateway to enhance GenAI service availability.

  • Configured the gateway to route requests to a backend pool of OpenAI resources distributed across multiple Azure regions.
  • Increased available rate limits by leveraging regional resource quotas, reducing the risk of throttling and service interruptions.
  • Significantly improved GenAI uptime and reliability for DataChat users by ensuring high availability and load balancing across regions.

LLM Access Ticketing Service: Proposed, designed, and implemented a ticketing service to prevent user abuse of limited LLM access and reduce rate limit errors.

  • Prioritized requests based on LLM type and the specific GenAI feature being used, ensuring fair and efficient resource allocation.
  • Utilized Redis-based queues and maps to manage and track ticket issuance and consumption in real time.
  • Improved overall reliability and user experience by minimizing rate limit errors and protecting critical LLM resources from abuse.

Custom LLM Deployment Research: Conducted in-depth research to evaluate options for deploying custom large language models (LLMs) in production.

  • Investigated and compared cloud providers and platforms (AWS, GCP, Modal) for LLM hosting, focusing on cost, scalability, and ease of integration.
  • Benchmarked hardware and infrastructure options to assess performance and cost trade-offs for LLM inference workloads.
  • Documented a future implementation pathway for custom LLM deployment, providing a roadmap for the team to follow as product needs evolved.

AutoML Suite: Collaborated with other developers to implement a user-facing AutoML suite that allows application users to train and evaluate multiple machine learning models on a dataset and automatically select the best-performing one.

  • Developed and integrated core ML pipeline steps such as data sanitization, feature pruning, temporal slicing, label binning, and feature imputation to improve model quality and robustness.
  • Overhauled the model management process to manage the use and persistence of models generated by users in DataChat, including designing a system that uses PostgreSQL to store model metadata and the file system to persist model binaries.
  • Managed cross-service data transfer to ensure seamless integration and efficient data flow between components of the AutoML system.

Other Contributions: In addition to the above, I have delivered critical bug fixes to address urgent customer needs and ensure platform stability. I have also led and contributed to several codebase refactors aimed at reducing technical debt, improving maintainability, and enabling faster feature development across teams.
